# View模块说明

## 文件结构

```
view/
├── __init__.py           # 包初始化文件
├── main_window.py        # 主窗口类
├── widgets.py           # 自定义控件
├── dialogs.py           # 对话框和弹出框
└── README.md            # 本说明文件
```

## 模块说明

### main_window.py
- **MainWindow类**: 应用程序主窗口
- 包含菜单栏、工具栏、状态栏和中央窗口布局
- 处理主要的用户交互和事件

### widgets.py
- **ClickableLabel类**: 可点击的标签控件
- 自定义的UI控件，可以根据需要扩展

### dialogs.py
- **ConnectEMPopup类**: 连接电镜的弹出框
- 可以添加更多的对话框和弹出框类

## 设计原则

1. **单一职责**: 每个文件负责特定的功能
2. **可复用性**: 控件和对话框可以在其他地方重用
3. **可维护性**: 代码结构清晰，易于维护和扩展
4. **模块化**: 功能模块化，便于测试和调试

## 扩展建议

- 可以继续拆分main_window.py中的功能模块
- 添加新的自定义控件到widgets.py
- 添加新的对话框到dialogs.py
- 考虑创建专门的布局管理模块
