# 图像显示功能说明

## 功能概述

本项目已实现完整的图像显示功能，包括：

1. **图像采集按钮**：点击工具栏的图像采集按钮可以触发图像采集
2. **图像显示区域**：主窗口中央的图像显示区域可以显示采集到的图像
3. **图像信息面板**：右侧信息面板显示图像的详细信息
4. **多种图像格式支持**：支持QImage、字节数据、文件路径等多种图像数据格式

## 使用方法

### 1. 通过图像采集按钮显示图像

1. 启动应用程序
2. 点击工具栏上的"图像采集"按钮
3. 系统会自动生成并显示一个示例图像
4. 图像会显示在主窗口中央的图像显示区域
5. 右侧信息面板会显示图像的详细信息

### 2. 程序化显示图像

```python
from view.main_window import MainWindow

# 创建主窗口
window = MainWindow()

# 显示QImage对象
from PyQt5.QtGui import QImage
image = QImage("path/to/image.jpg")
window.display_image(image)

# 显示字节数据
with open("image.jpg", "rb") as f:
    image_data = f.read()
window.display_image(image_data)

# 显示文件路径
window.display_image("path/to/image.jpg")
```

### 3. 测试图像显示功能

运行测试脚本：

```bash
python test_image_display.py
```

## 技术实现

### 1. 图像显示流程

```
图像采集按钮点击 → 发送信号 → MainWindow接收信号 → 调用图像采集方法 → 显示图像
```

### 2. 主要类和方法

#### MainWindow类
- `display_image(image_data)`: 显示图像的主要方法
- `show_qimage(image)`: 显示QImage对象
- `load_image_from_file(file_path)`: 从文件加载图像
- `scale_pixmap_to_fit(pixmap)`: 缩放图像以适应显示区域
- `update_image_info(image)`: 更新图像信息面板

#### MainToolbar类
- `imageCaptureRequested`: 图像采集请求信号
- `execute_image_capture()`: 执行图像采集的方法

### 3. 图像处理特性

- **自动缩放**：图像会自动缩放以适应显示区域
- **保持宽高比**：缩放时保持图像的原始宽高比
- **高质量缩放**：使用Qt.SmoothTransformation进行高质量缩放
- **错误处理**：完善的错误处理和用户提示

## 支持的图像格式

- **QImage对象**：PyQt5的QImage类
- **字节数据**：图像的原始字节数据
- **文件路径**：图像文件的路径字符串
- **常见图像格式**：JPEG、PNG、BMP、TIFF等

## 图像信息显示

右侧信息面板会显示以下图像信息：

- 文件名
- 图像尺寸（宽度 × 高度）
- 颜色深度
- 图像格式
- 文件大小
- 创建时间
- 修改时间

## 错误处理

系统包含完善的错误处理机制：

- 图像加载失败时显示错误消息
- 不支持的图像格式会给出明确提示
- 文件不存在时会显示相应错误信息
- 所有错误都会在状态栏显示

## 扩展功能

### 1. 添加新的图像源

要实现从电子显微镜获取图像，需要：

1. 在`start_image_acquisition()`方法中添加实际的图像采集逻辑
2. 使用`AgentClient`与本地服务器通信
3. 接收图像数据并调用`display_image()`方法

### 2. 图像处理功能

可以扩展添加：

- 图像滤镜和效果
- 图像测量工具
- 图像保存功能
- 图像对比功能

### 3. 实时图像流

要实现实时图像流显示：

1. 使用WebSocket接收图像数据
2. 在`ImageDisplayThread`中处理图像流
3. 通过信号将图像数据发送到主线程显示

## 注意事项

1. **线程安全**：图像显示操作应在主线程中进行
2. **内存管理**：大图像文件可能占用较多内存，注意及时释放
3. **性能优化**：对于高分辨率图像，考虑使用图像金字塔或分块加载
4. **错误恢复**：图像显示失败时，系统会自动恢复到默认状态

## 故障排除

### 常见问题

1. **图像不显示**
   - 检查图像数据格式是否正确
   - 确认图像文件是否存在且可读
   - 查看控制台错误信息

2. **图像显示异常**
   - 检查图像格式是否支持
   - 确认图像数据是否完整
   - 验证显示区域是否正确初始化

3. **性能问题**
   - 对于大图像，考虑降低分辨率
   - 检查内存使用情况
   - 优化图像处理算法

### 调试方法

1. 启用详细日志输出
2. 使用测试图像验证功能
3. 检查信号连接是否正确
4. 验证图像数据格式
